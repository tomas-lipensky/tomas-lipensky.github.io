# win-debug

[symstore.exe](https://docs.microsoft.com/en-us/windows/desktop/debug/symstore-command-line-options) ... [symstore](https://docs.microsoft.com/en-us/windows/desktop/debug/using-symstore) je nastroj na vytvareni knihoven symbolu (symbol store). Je obsahem balicku [Debugging Tools for Windows](https://docs.microsoft.com/en-us/windows-hardware/drivers/debugger/)  

### SrcSrv

SrcSrv (Source Server) je nastroj na vylistovani presnych verzi zrojaku pouzitych na vytvoreni aplikace (build)

[pdbstr.exe](https://docs.microsoft.com/en-us/windows-hardware/drivers/debugger/the-pdbstr-tool) ... nastroj na praci s .pdb soubory (indexovani) pro [SrcSrv](https://docs.microsoft.com/en-us/windows-hardware/drivers/debugger/srcsrv) (Source Server) a cteni streamu z PDB souboru  
[srctool.exe](https://docs.microsoft.com/en-us/windows-hardware/drivers/debugger/the-srctool-utility) ... seznam vsech naindexovanych souboru v PDB souboru
