/dev/tty0p0 ... ternminal device file  
/tev/ttyp0p0 ... modem dial-in  
/dev/cul0p0 ... modem dial-out  
/dev/cua0/0 ... Modem direct connect  
/dev/c0p0_1p ... Serial printer  
/dev/tty00 ... slave pseudo terminal - klient  
/dev/pty00 ... master pseudo terminal - server - 60 by default in kernel (npty, nstrpty)  
/dev/pts/0 .... streams- based pseudo slave - dtterm  
/dev/ptym0 ... streams- based master - dtterm  
/dev/rtape/tape0_BESTbn ... paskova mechanika, novy DSF, raw (znakovy pristup) nejlepsi zapis (hustota), n-eprevijet, b-erkley zapis  
/dev/rmt/c9t0d0BESTbn ... paskova mechanika, stary DSF, raw (znakovy pristup) nejlepsi zapis (hustota), n-eprevijet, b-erkley zapis  
/dev/disk/disk0 ... prvni disk, blokovy pristup, novy DSF  
/dev/rdisk/disk0 ... prvni disk, blokovy pristup, novy DSF  
/dev/dsk/c11t0d0 ... diskova cesta (disk), blokovy pristup, stary DSF  
/dev/rdsk/c11t0d0 ... diskova cesta (disk), znakovy pristup, stary DSF  
/dev/rchgr/autoch1 ... paskovy robot, novy DSF, raw (znakovy pristup)  
/dev/rac/c9t0d0 ... paskovy robot, stary DSF, raw (znakovy pristup)
