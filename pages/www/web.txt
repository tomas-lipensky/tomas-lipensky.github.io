====Staticke weby====

Lacine reseni na staticke weby jsou ulozna zarizeni na cloudech, jako treba:

  * Azure Storage Account - Blob
  * Google Storage
  * AWS S3
  * [[https://pages.github.com/|github]]

Napriklad Azure Storage Account nabizi sluzbu Static Web, ktera resi problem indexu.
