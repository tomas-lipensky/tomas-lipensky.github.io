=====lvm=====
[[http://docs.hp.com/en/B9106-90008/vxdg.1M.html|vxdg]] .. Spravuje Volume Manager diskove skupiny (disk groups)
vxassist make vol01 50m ... vytvori Volume vol01 o velikosti 50m
vxassist -g newDG make vol02 2g layout=raid5,nolog A2 A4 A5 ... vytvori Volume vol02 typu raid-5 o velikosti 2g
vxassist help showattr ... help
vxdg init newdg ... iniciuje novou diskovou skupunu newdg
vxdg init nevDG ndg-01=c0t0d0 ndg-02=c0t1d0 ... iniciuje DG nevDG a prida disky
vxdg list ... seznam diskovych skupin
vxdg adddisk newDG ndg-03=c2t5d0 ... prida disk do DG
vxdg rmdisk newDG ndg-03 ... odebere disk z DG
vxdg deport newDG ... exportuje diskovou skupinu
vxdg import newDG ... importuje diskovou skupinu
vxdg destroy ... zrusi diskovou skupinu
vxdg -g newDG free ... volne misto na discich
vxdisk list ... seznam dostupnych disku
vxdisk -g nevVG list ... seznam disku ve skupine newDG
vxdisk -o alldgs list ... seznam vsech DGs, i tech exportovanych
vxdisk -s list ... seznam LUNu\\
vxdiskadm ... interaktivni sprava LVM
vxdisksetup -v
vxdisksetup -i c2t0d0 format=sliced ... iniciuje disk k pouziti ve VVM, ale neprida do Diskove skupiny (zapise data do private region)
vxdiskunsetup -C c2t3d0 ... odebere disk z Veritas kontroly - zmaze data v private regoin
vxedit -g newDG rename ndg-01 newDG-disk01 ... prejmenuje disk
vxedit -g newDG set nohotuse=on ndg-01 ... nastavi nohotuse
vxevac -g newDG ndg-01 ndg-03 ... evakuace dat napr. pred vymenou disku
vxprint -Aht ... Seznam disku a LV
vxprint -g newDG ... seznam komponent DG newDG
vxdisk list ... Seznam PV

vxupgrade -n 4 /mount_point ... online update veritas 3 na veritas 4
vxfsconvert ... offline verze update veritasu

/etc/default/vassist
