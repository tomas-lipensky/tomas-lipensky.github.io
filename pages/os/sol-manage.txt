
======Sprava systemu - uzivatele, balicky, jadro, logy...======

admintool ... manazer nastaveni systemu
boot ... poradi bootovacich medii
luxadm ... administrace diskovych poli
luxadm -v display
luxadm -v port
dmesg ... zpravy z jadra
/usr/platform/`uname -i`/sbin/prtdiag -v ... informace o hardware
modinfo ... informace o nactenych modulech v jadru
modload ... nacte modul do jadra
modunload ... odstrani modul z pameti v jadre
prtconf ... ukaze nastaveni systemu
psrinfo ... informace o procesoru
sar ... (System acrivity report)
showrev ... ukaze informace o OS
top
vmstat ... (virtual memory statistics)
swap -l ... ukaze informace o swapu
echo '$c' | adb -k /var/crash/`hostname`/vmunix.0 ... analyza system dumpu
pstack core.2580 ... analyza dumpu
[[http://uk.sun.com/service/stb/index.jsp|Explorer Data Collector]] ... sberac dat o systemu

=====Zarizeni=====
admintool ... graficky manazer nastaveni systemu (uzivatele, tiskarny, hosts atd.)
iostat -ne ... statistika chub v tabulce
iostat -En ... upovidana statistika I/O zarizeni
prtvtoc /dev/rdsk/c0t1d0s0 ... informace o fyzickem disku - oddily, velikost atd.
drvconfig ... vytvari zarizeni v /devices
devfsadm ... udela vsechny prikazy: disks, tapes, atd.
devlinks ... vytvori /dev/ zarizeni pro pseudo zarizeni a doplnkove zarizeni
disks ... vytvori /dev/ zarizeni pro disky
tapes ... vytvori /dev/ zarizeni pro paskove mechaniky
ports ... vytvori /dev/ zarizeni pro seriove porty
rem_drv ... odinstalovani ovladace zarizeni
sysdef ... seznam nainstalovanych zarizeni
/etc/minor_perm ... prava nove vytvarenych zarizeni


=====Balicky, programy, software=====
pkgadd ... pridani balicku
pkgadd -d /patch nmap-4.76-sol9-intel-local ... nainstaluje balicek /patch/nmap-4.76-sol9-intel-local
pkgadd -d . -s spool SMCnmap ... presune balicek SMCnmap z aktualniho adresare do /var/spool/pgk
pkgchk ... otestuje nainstalovany balicek
pkgchk -l -P /usr/bin/showrev ... napise, zda je nainstalovany tento soubor, pod jakym balickem atd.
pkginfo ... vylistovani nainstalovanych balicku
pkginfo -l ... vylistovani podrobnych informaci o nainstalovanych baliccich
pkgparam ... informace o baliccich
find /usr/package | pkgproto > Prototype ... vytvareni definice balicku pro pkgmk\\
pkgrm ... odebere balicek
pkgtrans -s Product /var/tmp stream.pkg SUNWzlib SUNWftpr ... Prevede balicek, ktery je adresar, na stream balicek
pkgmk ... vytvoreni balicku. [[http://www.ibiblio.org/pub/packages/solaris/sparc/html/creating.solaris.packages.html|Postup na tvorbu balicku]]\\
patchadd 114568-24 ... Nainstaluje patch 114568-24
patchadd -p ... ukaze nainstalovane patche
patchrm 114568-24 ... odinstaluje patch 114568-24
showrev -p ... ukaze nainstalovane patche
/var/sadm/install/contents ... vsechny nainstalovane balicky, soubory zmeny
/var/sadm/patch ... seznam patchu
/var/sadm/pkg ... seznam nainstalovanych balicku
[[http://sunsolve.sun.com|sunsolve.sun.com]] ... patche pro Solaris
