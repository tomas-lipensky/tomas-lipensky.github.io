# YAML

YAML Ain't Markup Language, koncovka .yml nebo [.yaml](https://yaml.org/)

## Struktura

```yaml
---
objekt:
  hodnota: klic
  cislo: 80
  sviti_slunce: true
  je_patek: yes
  nic: null
  seznam: # komentář
    - pejsek
    - kocicka
  dlouha_hodnota: >
    toto je způsob
    zalamování dlouhého řádku
  dalsi_dlouha_hodnot:
    text
    který
    je
    moc
    dlouhý
  multi_radek: |
    text na
    více řádků

```
